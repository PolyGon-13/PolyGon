ranges와 intensities 값은 각각 센서에서 측정한 거리 값들의 배열과 각 거리 측정에 대응하는 반사강도인데 samples가 360이어서 360개에 해당하는 값이 각각 계속 표시되어 다른 값들을 볼 수가 없다.

import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan

class ScanFieldPrinter(Node):
    def __init__(self):
        super().__init__('scan_filter_node')
        self.subscription = self.create_subscription(
            LaserScan,
            '/scan',
            self.listener_callback,
            10
            )
        
    def listener_callback(self, msg: LaserScan):
        print(f"header.stamp.sec : {msg.header.stamp.sec}")
        print(f"header.stamp.nanosec : {msg.header.stamp.nanosec}")
        print(f"header.frame_id : {msg.header.frame_id}")
        print(f"angle_min : {msg.angle_min}")
        print(f"angle_max : {msg.angle_max}")
        print(f"angle_increment : {msg.angle_increment}")
        print(f"time_increment : {msg.time_increment}")
        print(f"scan_time : {msg.scan_time}")
        print(f"range_min : {msg.range_min}")
        print(f"range_max : {msg.range_max}")
        print('---------------------------')

def main(args=None):
    rclpy.init(args=args)
    node=ScanFieldPrinter()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    node.destroy_node()
    rclpy.shutdown()

if __name__=='__main__':
    main()

gazebo=IncludeLaunchDescription(

    ),

world는 gazebo의 월드와 관련된 인자이고 lidar.launch.py의 해당 부분에서 gazebo_ros/launch/gazebo.launch.py를 실행시키는 부분이 있으므로 해당 파일 부근을 찾아보았다. (/opt/ros/humble/share/gazebo_ros/launch)

return LaunchDescription([
    DeclareLaunchArgument(
        'world', default_value=[FindPackageShare('gazebo_ros'), '/worlds/empty.world'],
        description='Specify world file name. Defaults to an empty world.'
    ),

같은 파일 위치의 gzserver.launch.py 파일 97번째 줄에 해당 내용이 포함되어 있는 것을 확인하였다. 기본적으로 empty.world를 실행시키고 인자를 따로 받는다면 해당 world를 실행시키는 것 같다.
